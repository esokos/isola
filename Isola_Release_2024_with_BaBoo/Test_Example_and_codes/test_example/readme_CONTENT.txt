CONTENT of folder test_example

The folder contains all necessary *.exe files from codes\Fortran_executables
The folder contains all necessary *.m   files from codes\Matlab_source

The folder contains all necessary input data to run the test example.
They were prepared in a previous run of ISOLA GUI (requiring installation of complete Isola).
The data include:  

four files as in standard Isola:
allstat.dat: codes of (11) used stations and frequency band
*raw.dat instrumentally corrected velocity for the used stations
elemse*.dat: elementary seismograms for (20) trial source positions
inpinv.dat: control parameters for the inversion (self-explanatory)

specific input file for Bayesian bootstrap
isorandinp.inp: number of perturbations, tested trial source positions and times (self-explanatory)
