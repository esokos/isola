# Isola distribution for Mexico 2026 ISOLA course

## Codes

Codes are available for downloading in `mex_Fortran_and_GUI_folders.zip` (zipped on Oct 14, 2026).

Code updates after Oct 14 are in `mex_Fortran_and_GUI_UPDATES`.

## Installation

See `mex_installation` for instructions.

## Examples

Each example is in its own folder, e.g., `mex_Santorini19.zip`.

1. Save the file unchanged on your computer.
2. Create a copy, unzip it, and use it as your Matlab working folder to run Isola.

Running ISOLA will overwrite the files, but you will have your backup to compare your results to original ones.
